# Demostración para Instructores - Agentes en acción con Copilot Studio

El propósito de este documento es sugerir la demostación que el instructor puede realizar durante la entrega del seminario Agentes en acción con Copilot Studio. Los siguientes pasos son generales, se entiende que el instructor tiene las habilidades para comprenderlo. Están organizados en orden de los slides de Power Point adjuntos. 

## Crear un agente básico
* Entrar a Copilot Studio
* Crear un agente
* Configurar las instrucciones y configuraciones básicas

## Agregar conocimiento a tu agente con tus datos
* Acceder al agente creado previamente
* ver las fuentes de datos disponibles
* Seleccionar una de las fuentes y configurarla
* Probar el agente para validar que la respuesta esté contextualizada

## Agregar acciones a tu agente a través de herramientas
* Acceder al agente creado previamente
* Ver las conexiones de herramientas que se pueden configurar para realizar acciones
* Seleccionar una de las herramientas
* Configurarla para realizar una acción acorde al escenario
* Probar el agente para validar que realice las acciones

## Evalúa tu agente y explora configuraciones avanzadas en Microsoft Copilot Studio
* Ingresa al agente que creaste
* Crear un conjunto de pruebas
* Explica las diferentes opciones de evaluación
* Usa la evaluación de respuesta única y si es posible construye un template en CSV para cargarlo
* Pruébalo y revisa los resultados

## Publicar y compartir tu agente
* Comparte el agente con alguien. Valida que esa persona tenga acceso
* Publica el agente en un canal
* Usa el agente en el canal
